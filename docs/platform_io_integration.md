# Integrating Generated UI with PlatformIO

This guide provides a step-by-step process for compiling and using the C-code generated by `lvgl_ui` within a standard PlatformIO-based embedded project.

This method avoids duplicating any code from the `lvgl_ui` repository. It uses a `library.json` file to instruct PlatformIO to compile the necessary runtime files directly from their original locations, treating them as a local library.

### Prerequisites

We will assume a directory structure where your PlatformIO project and the `lvgl_ui` generator repository are located. The LVGL graphics library itself will be managed by PlatformIO as a dependency.

```
Workspace/
├── MyPioProject/          <-- Your embedded project
│   ├── platformio.ini
│   ├── src/
│   │   └── main.c
│   └── lib/               <-- Your own project-specific libraries (can be empty)
│
└── lvgl_ui/               <-- The generator repository
    ├── data_binding.c
    ├── pio_library/
    │   └── library.json
    └── ... (other generator files)
```

### Step 1: Add `lvgl_ui` as a Git Submodule

The cleanest way to include the generator and its runtime is as a git submodule. This links your project to a specific version of the toolchain, making your build reproducible.

In the root directory of `MyPioProject`, run the following command:

```bash
# Replace the URL with the actual URL of your lvgl_ui git repository
git submodule add https://github.com/user/lvgl_ui.git lvgl_ui
```

This will clone the generator into a folder named `lvgl_ui` inside your project. Your project structure will now look like this:

```
MyPioProject/
├── platformio.ini
├── src/
│   └── main.c
├── lib/
└── lvgl_ui/  <-- The submodule we just added
    ├── pio_library/
    │   └── library.json
    └── ...
```

### Step 2: Configure `platformio.ini`

You need to tell PlatformIO about the LVGL dependency and where to find the `lvgl_ui` runtime library.

```ini
[env:your_board]
platform = ...
board = ...
framework = ...

# 1. Add the path to the generator's root directory.
#    PlatformIO will scan this folder and find "pio_library/library.json".
lib_extra_dirs = lvgl_ui

# 2. Add LVGL as a dependency.
#    This tells PlatformIO to download LVGL from its official repository.
#    The files will be stored in your project's ".pio/libdeps" directory.
lib_deps =
    https://github.com/lvgl/lvgl

build_flags =
    # Define the size of your LVGL display buffer
    -D LV_HOR_RES_MAX=480
    -D LV_VER_RES_MAX=320
```
When you build, PlatformIO will:
1.  Download LVGL into `.pio/libdeps/your_board/lvgl`.
2.  Find `lvgl_ui/pio_library/library.json`, compile the source files listed within it (`data_binding.c`, `utils.c`, etc.) into a static library (`liblvgl_ui_runtime.a`).
3.  Automatically link both LVGL and the runtime library with your final application.

### Step 3: Create Your UI Specification

It's good practice to keep your UI definition files inside the `lvgl_ui` submodule directory.

Create your UI file, for example: `lvgl_ui/ui/main_screen.yaml`:

```yaml
- type: obj
  id: '@screen'
  width: 100%
  height: 100%
  flex_flow: column
  flex_align:
    main: center
    cross: center
    track: center
  flex_pad:
    row: 10
  children:
    - type: label
      id: '@counter_label'
      text_font: '@lv_font_montserrat_24'
      observes:
        counter:
          text: "Count: %d"

    - type: button
      action:
        increment: trigger
      children:
        - type: label
          text: "Increment"

    - type: switch
      id: '@power_switch'
      action:
        toggle_power: toggle

```

### Step 4: Generate the C-Code

Run the generator tool and redirect its output into your PlatformIO project's `src` folder.

From within the `lvgl_ui` directory (after you have built the generator executable):

```bash
# On Linux/macOS
./build/lvgl_ui data/api_spec.json ui/main_screen.yaml --codegen c_code > ../MyPioProject/src/create_ui.c

# On Windows
.\build\lvgl_ui.exe data\api_spec.json ui\main_screen.yaml --codegen c_code > ..\MyPioProject\src\create_ui.c
```
This will create a `create_ui.c` file inside your project's `src` directory.

### Step 5: Write Your Application Logic

Finally, modify your `main.c` to initialize the runtime, create the UI, and handle its actions.

`MyPioProject/src/main.c`:

```c
#include <Arduino.h> // Or your platform's equivalent header
#include "lvgl.h"
#include "lvgl_ui.h" // The single header for the runtime library and generated UI

// --- Application State ---
static int32_t counter_value = 0;
static bool power_state = false;

// --- UI Action Handler ---
// This function will be called by the data binding system when a UI action occurs.
void ui_action_handler(const char* action_name, binding_value_t value, void* user_data) {
    if (strcmp(action_name, "increment") == 0) {
        counter_value++;
        // Notify the UI that the 'counter' state has changed.
        // The label observing this state will automatically update.
        data_binding_notify_state_changed("counter", (binding_value_t){.type = BINDING_TYPE_FLOAT, .as.f_val = (float)counter_value});
    }
    else if (strcmp(action_name, "toggle_power") == 0) {
        power_state = value.as.b_val;
        printf("Power state is now: %s\n", power_state ? "ON" : "OFF");
        // You could notify other UI elements about the power change here if needed.
    }
}

void setup() {
    Serial.begin(115200);
    printf("LVGL UI Demo\n");

    // 1. Initialize LVGL and your display/touch drivers
    lv_init();
    // ... your display/touch driver initialization code ...
    // e.g., tft.begin(); etc.

    // 2. Initialize the UI Runtime Library
    // This sets up the data binding and object registry systems.
    lvgl_ui_init();

    // 3. Register your application's action handler
    data_binding_register_action_handler(ui_action_handler, NULL);

    // 4. Create the UI by calling the generated function
    create_ui(lv_screen_active());

    // 5. Set the initial state for the UI
    // This ensures the UI reflects the application's state at startup.
    data_binding_notify_state_changed("counter", (binding_value_t){.type = BINDING_TYPE_FLOAT, .as.f_val = (float)counter_value});
}

void loop() {
    lv_timer_handler(); // let LVGL handle its tasks
    delay(5);
}
```

### Step 6: Build and Upload

You're all set! You can now build and upload your project using the standard PlatformIO commands:

```bash
pio run -t upload
```
